# Dashy

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

A self-hosted start page for your home lab, running on your Home Assistant server.

[Dashy](https://dashy.to/) puts all your services, bookmarks and widgets on one page, with
status checks that show what is up, a search bar, keyboard shortcuts, and dozens of themes.

- Log in with your Home Assistant account; nothing to set up.
- Edit the dashboard in the browser, or in `conf.yml` in the app configuration folder.
- Starts with a ready-made dashboard you can build on.
- Keeps the configuration in Home Assistant backups.
- Opens from the app page, the Companion app, or a sidebar dashboard.

See the **Documentation** tab for installation and configuration.
